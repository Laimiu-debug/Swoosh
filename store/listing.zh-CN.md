## 简介

把文件、文件夹和文字，轻快地递给同一局域网中的另一台 Windows 电脑。无需注册，传输无需互联网。

## 详细描述

Swoosh 是一个轻快的本地传输工具。让两台电脑连上同一可互通的局域网，再选内容、选设备，核对两端短码后开始传输。

拖入文件，选择整个文件夹，或输入一段文字。收到的文件默认保存在「下载 / Swoosh」中，可以设置其他接收文件夹并自动记住，传输历史可以一键打开接收文件夹。接收的文字可以主动复制到剪贴板。

附近的设备会自动出现在列表中；发现不到时，可以手动输入对方电脑的局域网 IP 与端口。连接采用 TLS，发送与接收双方都需要确认。内容直接在设备之间传输，不经过文件中转服务器。

应用支持浅色、深色和跟随系统主题，无需注册账号，不集成广告。

使用前请确认两端都已安装并打开兼容版本的 Swoosh，网络允许设备互通。防火墙或路由器设备隔离可能影响发现和连接。初次下载安装以及补装 WebView2 运行环境可能需要互联网；传输本身不依赖互联网。

当前版本仅支持 Windows 电脑之间传输。手机端、扫码连接、可信设备免确认和断点续传仍在规划中。文字需要主动发送，不会自动读取或持续同步剪贴板。当前协议不声明 LocalSend 兼容。

Microsoft Store 版计划采用一次性购买，不提供订阅。相同项目的技术预览版也可从官网和 GitHub 免费下载。

## 功能条目

- 传输文件、文件夹和图片文件，保留目录结构。
- 主动发送文字，接收后点击复制。
- 局域网自动发现，支持手动输入 IP 与端口连接。
- TLS 连接与双方短码确认。
- 接收文件校验，重复接收建立独立目录，不覆盖上次内容。
- 本机传输历史与接收文件夹快捷打开。
- 自定义接收位置，重启后保留，支持恢复默认。
- 浅色、深色与跟随系统主题。
