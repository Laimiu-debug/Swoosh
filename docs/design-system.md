# Swoosh 设计系统

版本：0.1。更新日期：2026 年 10 月 6 日。

Swoosh 的界面简单、轻快，主要操作一眼可见。用轻微带绿的白色背景、薄荷绿强调色、清楚的文字层级和短动效表达亲切感。可爱来自图形和细节，不依靠大面积装饰。

## 1 视觉原则

- 内容先于装饰。设备、文件和进度是页面的主要信息。
- 每个区域只有一个明确主操作。发送流程为选择内容，再点击设备。
- 留白让分组清晰，边界使用浅色描边和少量阴影。
- 界面文案短而具体，失败时给出能执行的动作。
- 所有状态同时用文字或图标表达，颜色不承担唯一含义。

## 2 品牌与图标

显示名称为 Swoosh，仓库与包名使用小写 `swoosh`。产品短句为“选一下，嗖过去。”，只在首页或引导中少量使用。

品牌图形采用向右飞行的“小信使”：扬起的翅膀、柔软的身体、小眼睛与短喙组成亲切的鸟形轮廓。应用图标以薄荷绿和纸白为主，翅膀内侧用浅薄荷，短喙用浅杏色；浅深色界面使用同一品牌色。导航中的单色标志保留轮廓与镂空眼睛，可以随文字色变化。16 px 版本去掉翅膀内侧色块并放大眼睛，减少细节干扰。

图标资源已提供 SVG、16 至 1024 px PNG 与 Windows ICO，完整说明见 [品牌资源](../design/brand/README.md)，视觉适配见 [图标预览](../design/brand/preview.html)。图标由同一份轮廓数据生成，首页内联标志与独立资源同步；Windows Tauri 程序和安装包已接入，移动平台完整图标集将在平台开发时生成。

界面图标使用统一的圆角线性风格，基准尺寸 20 px，大图标 24 px，线宽建议 1.75 至 2 px。图标按钮必须有可访问名称；关键动作同时显示文字，不用 Emoji 代替功能图标。

本次品牌设计参考 [Anthropic frontend-design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md) 的原则：让视觉选择服务于实际产品，把主要识别集中在一个元素上，并通过真实截图检查尺寸和背景适配。Swoosh 将飞行的小信使作为品牌记忆点，界面继续保持留白与安静的系统字体。

## 3 令牌文件与使用方式

| 文件 | 用途 |
| --- | --- |
| `design/tokens.json` | 唯一令牌源文件，包含基础值和浅深色语义映射 |
| `design/tokens.css` | 生成后的 CSS 自定义属性，供组件引用 |
| `scripts/generate-tokens.mjs` | 校验引用与主题一致性，生成 CSS |
| `design/preview.html` | 离线可打开的组件与配色预览 |

JSON 采用项目轻量格式，叶节点具有 `$type` 与 `$value`，引用形如 `{palette.mint.700}`。维度和时长以 CSS 字符串表示，数字保持数字，贝塞尔曲线使用四项数组；它不是对完整 DTCG 标准的兼容声明。

基础值包括 `palette`、`font`、`space`、`radius`、`control`、`focus`、`layout`、`motion` 和 `zIndex`。主题位于 `themes.light` 与 `themes.dark`；两套主题必须拥有完全相同的语义令牌。

生成名称采用 `--sw-` 前缀与 kebab-case。组件引用语义颜色，不直接引用基础色盘；间距与尺寸可以直接引用基础令牌。

```css
@import "../design/tokens.css";

.primary-button {
  min-height: var(--sw-control-height);
  padding-inline: var(--sw-space-4);
  border-radius: var(--sw-radius-control);
  background: var(--sw-color-primary);
  color: var(--sw-color-on-primary);
}

.primary-button:focus-visible {
  outline: var(--sw-focus-width) solid var(--sw-color-focus);
  outline-offset: var(--sw-focus-offset);
}
```

CSS 默认跟随系统主题。应用设置选择浅色或深色时，在根元素设置 `data-theme="light"` 或 `data-theme="dark"`；跟随系统时移除该属性。主题选择由应用设置持久化。

## 4 颜色

主色是薄荷绿，深色文字与浅背景保持足够对比。杏色只用于少量插画或非关键标签，成功、警告和失败使用独立状态色。

| 语义令牌 | CSS 变量 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- | --- |
| 背景 | `--sw-color-background` | `#F7FAF9` | `#10211B` | 页面画布 |
| 表面 | `--sw-color-surface` | `#FFFFFF` | `#142820` | 内容面板和弹窗 |
| 次级表面 | `--sw-color-surface-subtle` | `#F0F5F2` | `#1B322A` | 内容分组和弱强调区域 |
| 主文字 | `--sw-color-text-primary` | `#142820` | `#F0F5F2` | 标题与正文 |
| 次文字 | `--sw-color-text-secondary` | `#4E655B` | `#BED0C5` | 说明与次级信息 |
| 辅助文字 | `--sw-color-text-muted` | `#5D7368` | `#A3B9AD` | 时间与辅助标签 |
| 主操作 | `--sw-color-primary` | `#087F6B` | `#6DD6BB` | 主按钮、活动标签和进度 |
| 主操作文字 | `--sw-color-on-primary` | `#FFFFFF` | `#10211B` | 实色主按钮中的文字 |
| 轻强调背景 | `--sw-color-primary-soft` | `#EDF9F4` | `#193C31` | 已配对和当前选择 |
| 轻强调文字 | `--sw-color-on-primary-soft` | `#086653` | `#85D9BE` | 轻强调区域文字 |
| 普通边界 | `--sw-color-border` | `#D9E5DD` | `#345145` | 装饰性面板分隔 |
| 控件边界 | `--sw-color-border-strong` | `#7A9188` | `#7A9188` | 输入框与必要控件轮廓 |
| 成功 | `--sw-color-success` | `#147D50` | `#82D9A4` | 已收到与已完成 |
| 警告 | `--sw-color-warning` | `#8B5B11` | `#F0C36B` | 等待确认与空间提醒 |
| 失败 | `--sw-color-danger` | `#B6453F` | `#FFABA4` | 失败与危险操作 |

状态文字搭配对应 `*-soft` 背景使用。普通边界用于布局分隔，不承担输入框唯一可识别轮廓。输入框用控件边界或其他有足够对比的明确形状。

## 5 字体与文字层级

采用系统字体栈，中文优先使用平台可用的中文无衬线字体。首版不下载在线字体，保持离线启动。配对码和地址使用等宽字体。

| 层级 | 字号 | 字重 | 行高 | 使用位置 |
| --- | --- | --- | --- | --- |
| Hero | 32 px | 600 | 1.25 | 首页短标题，每页至多一处 |
| Title | 24 px | 600 | 1.25 | 页面或弹窗标题 |
| Subtitle | 18 px | 600 | 1.4 | 区域标题与设备名 |
| Body | 16 px | 400 | 1.6 | 正文与主要操作 |
| Label | 14 px | 500 | 1.4 | 次级按钮、标签和说明 |
| Caption | 12 px | 400 | 1.4 | 时间等非关键辅助信息 |

关键操作和错误提示不使用 Caption。正常文字至少满足 4.5:1 对比，大字与必要控件边界至少 3:1；焦点可见且不被遮挡。界面支持字体缩放与键盘操作。[WCAG 2.2](https://www.w3.org/TR/WCAG22/)

## 6 间距与布局

采用 4 px 基础网格。常用间距为 8、12、16、24、32 px；大区域之间使用 32 或 48 px。元素靠分组与留白形成层级，不叠加过多卡片。

| 项目 | 规格 |
| --- | --- |
| 页面内容最大宽度 | 1120 px |
| 桌面页面边距 | 32 px |
| 移动页面边距 | 20 px |
| 控件最小高度与点击目标 | 44 px |
| 文件与文字区域内部间距 | 24 px，紧凑布局降为 16 px |
| 弹窗最大宽度 | 440 px |
| 设备卡片间距 | 12 px |
| 控件圆角 | 12 px |
| 设备卡片圆角 | 16 px |
| 大面板圆角 | 20 px |

600 px 以下使用单列，设备卡片纵向排列；600 至 959 px 使用紧凑布局；960 px 及以上可以将发送区域与任务信息并排。预览页面的令牌面板属于设计说明，不属于产品首页。

断点值也记录在 JSON 中。CSS 媒体查询不能直接使用普通 `var()`，因此布局样式中的断点字面值需要与令牌同步。桌面窗口初始尺寸建议 960 × 720，最小尺寸建议 760 × 560；较小窗口允许滚动，不裁剪主操作。

## 7 组件与状态

| 组件 | 默认 | 悬停与按下 | 禁用与错误 |
| --- | --- | --- | --- |
| 主按钮 | Primary 底色、On Primary 文字、44 px 高 | Primary Hover 与 Primary Pressed | Disabled Background 与 Disabled Text，保留明确状态 |
| 次按钮 | Surface、Text Primary、控件边界 | Surface Hover | 同主按钮禁用规则 |
| 文字入口 | Surface、控件边界、可见标签 | 聚焦显示 Focus 描边 | 错误边界与错误说明同时出现 |
| 设备卡片 | Surface、轻边界、设备图标与名称 | Surface Hover，按下轻强调 | 离线显示文字；不能只降低透明度 |
| 文件选择区 | Primary Soft、控件边界、选择按钮 | 拖入可发送内容时加强边界 | 无法读取时显示具体文件与重选入口 |
| 进度区域 | Primary 进度条、任务文字 | 显示字节进度 | 失败停止进度动画，提供重试 |
| 提示消息 | 状态背景、图标、短文本 | 无悬停依赖 | 可恢复错误包含行动入口 |

所有可操作组件显示键盘焦点。加载时保留按钮宽度、显示动作文字，避免页面跳动；重复提交由核心状态和界面共同限制。图标按钮的点击范围至少 44 × 44 px。

### 文件与文字切换

两种内容入口使用短标签“文件”“文字”。标签状态由位置、形状和颜色共同表达，切换保留用户已经选中的内容。标签支持键盘左右键，关联面板有可访问名称。

### 设备卡片

每张卡片包含设备图标、名称、类型和状态。已配对状态用小型标签表达，自动接收只在详情中解释。卡片按下直接发起所选内容的发送；没有内容时引导选择，不发送空任务。

### 接收与配对弹窗

接收弹窗只展示必要信息和“拒绝”“接收”。配对短码单独显示，说明双方核对的目的；“记住设备”与“自动接收”分别设置。弹窗限制在视口内，内容可滚动；关闭后焦点回到触发按钮。

## 8 动效与声音

| 令牌 | 时长 | 使用 |
| --- | --- | --- |
| Fast | 120 ms | 按钮颜色和标签状态 |
| Normal | 180 ms | 小面板、提示出现 |
| Slow | 240 ms | 弹窗进入 |
| Send | 360 ms | 单次纸飞机发送动画 |

标准缓动为 `cubic-bezier(0.2, 0, 0, 1)`，退出缓动为 `cubic-bezier(0.4, 0, 1, 1)`。不使用持续弹跳、设备列表呼吸灯或等待动画代替实际进度。完成反馈不会延迟文件打开。

系统减少动态效果开启时，时长令牌归零，同时关闭位移动画与循环动画。首版不加入音效；后续音效默认关闭，用户可主动开启。

## 9 页面文案

| 场景 | 建议文案 |
| --- | --- |
| 首页标题 | 选一下，嗖过去。 |
| 文件入口 | 把文件拖到这里 |
| 文件选择 | 选择文件 |
| 文件夹选择 | 选择文件夹 |
| 文字占位 | 贴一段文字，发到另一台设备。 |
| 设备列表 | 发给谁 |
| 发现空态 | 还没找到设备，确认对方已打开 Swoosh。 |
| 手动入口 | 连接我的设备 |
| 传输进行中 | 正在发送 |
| 文件完成 | 已收到 |
| 文字操作 | 复制 |
| 网络失败 | 暂时连不上这台设备 |

文案优先使用用户熟悉的词语。主流程不展示技术协议名，不使用“惊喜”“魔法”等装饰性提示替代真实结果。

## 10 设计交付验收

- 检查浅深色主题的主文字、辅助文字、主按钮、状态文字和焦点对比。
- 检查 390 px 手机宽度与桌面宽度，没有横向溢出或裁剪。
- 200% 文字缩放后仍可阅读并完成主要操作。
- 输入、标签、设备和弹窗都能通过键盘操作，焦点始终可见。
- 空态、发现中、等待确认、传输、校验、失败、拒绝、取消和完成都有明确呈现。
- 减少动态效果时仍保留状态变化，发送动画不执行位移。
- 前端颜色通过语义令牌引用；修改 JSON 后执行生成与一致性检查。

设计预览使用本地演示数据，只用于检查方向与组件。真实的局域网发现、接收、配对和传输以后按开发需求实现。
